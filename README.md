# KlineSimilarity（韭菜模拟器）

一个按 `K线模拟.md` 实现的本地静态 Web 模拟训练程序，支持导入真实日线数据后进行盲选模式或资产配置模式训练。

## 功能

- CSV / JSON 数据导入，字段遵循 PRD：`symbol,name,date,open,high,low,close,volume,pre_close`
- 数据校验与标的选择，少于 100 个交易日的标的不可选
- 盲选模式隐藏真实名称，资产配置模式显示名称代码
- 日线 / 周线 / 月线周期切换，均线与指标按所选周期重算
- K 线、成交量、MA5/10/20/60/120/250 与 MACD/KDJ/RSI/WR/BOLL/OBV/BIAS/BRAR
- 画线工具：趋势线、水平线（按日期与价格锚定），支持撤销/清除
- 图表标注当前区间的最高价/最低价
- 逐日步进、T+1 交收（当日买入次日才能卖出，卖出资金当日可继续买入）
- 每笔下单可单独选择成交价口径：当日收盘价即时成交，或次日开盘价挂单（可撤销）
- 止盈止损条件单，触发后按当日收盘价自动卖出
- 佣金、印花税、滑点、成交容量与涨跌停流动性折减
- 持仓、交易流水、终止清仓、收益率和最大回撤统计
- 复盘统计：完整交易笔数、胜率、盈亏比、平均盈亏、最大连续亏损、交易复盘列表

## 运行

直接打开 `index.html` 即可。若浏览器限制本地 `fetch`，用任意静态服务器打开：

```bash
npx serve .
```

## 数据

仓库内已随包分发 422 只 A 股主板日线的十年数据（`data/a_share_daily_10y.json` 与页面内置的 `data/sample-data.js`），打开即可使用，无需联网取数。

如需换成自己的标的池，在页面右上角「导入数据」上传 CSV / JSON 即可，字段要求见上面第 1 条。

> 注：仓库不包含任何通过外部数据接口抓取数据的脚本，也不含任何密钥，请勿在其中提交个人账号凭证。
